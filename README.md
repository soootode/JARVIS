# Jarvis

> AI-powered cognitive scaffolding assistant for planning, reflection, and executive function support.

## 🚧 Project Status

Jarvis is currently under active development.

The current version focuses on building a personal AI assistant with:

- 🧠 Long-term memory
- 💬 Context-aware conversations
- 📅 Smart planning and scheduling
- ✅ Task management
- 🔔 Notifications and reminders
- 🤖 Personalized AI interactions

## Long-Term Vision

Jarvis is **not** intended to be just another chatbot or productivity application.

The long-term goal is to explore **AI as Cognitive Augmentation** by building a **Cognitive Scaffolding System** that helps users:

- Reduce mental clutter
- Improve executive functioning
- Support structured thinking
- Increase clarity before action
- Preserve autonomy instead of creating dependency

This project combines ideas from:

- Artificial Intelligence
- Cognitive Science
- Human-Computer Interaction (HCI)
- Computational Cognitive Modeling
- Long-term Memory Systems

## Current Focus

At this stage, the priority is building a reliable personal productivity assistant for everyday use while gradually evolving the architecture toward a cognitive support system.
